# Sah-AI (Next.js App)

This is the Next.js application for Sah-AI. See the [root README](../README.md) for project overview, architecture, and setup instructions.

## Quick Start

```bash
npm install
cp .env.example .env.local
# Add your GEMINI_API_KEY to .env.local
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm test` | Run safety library tests (vitest) |
| `npm run lint` | Run ESLint |
